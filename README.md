# ⚡ ACTIVEPULSE SPORTS | ร้านค้าเสื้อผ้าและรองเท้ากีฬาออนไลน์

เว็บแอพพลิเคชันร้านค้าออนไลน์สำหรับจำหน่าย **เสื้อผ้าและรองเท้ากีฬาแบรนด์ชั้นนำ** (เช่น Nike, Adidas, Puma, Jordan, Asics และ ActivePulse) ดีไซน์สีสันสดใส ทันสมัย มีพลัง (Athletic Energy) พร้อมระบบตะกร้าสินค้าและการทำงานที่สมบูรณ์ ใช้งานได้จริง 100%

---

## 🌟 ฟีเจอร์เด่นของระบบ (Key Features)

### 1. 🎨 ดีไซน์สีสันสดใส & ทันสมัย (Vibrant Athletic UI)
- โทนสีนีออน ส้มเพลิง (Flame Orange), ชมพูสด (Vibrant Pink), เขียวนีออน (Neon Lime) และ ดำออบซิเดียน (Obsidian Black)
- เอฟเฟกต์ Glassmorphism, เงาเรืองแสง (Neon Glow) และ Micro-animations เมื่อเลื่อนเมาส์
- แถบป้ายลดราคา (Discount Tag), แถบสินค้าขายดี (HOT) และ สินค้าเข้าใหม่ (NEW)
- รองรับการแสดงผลทุกหน้าจออย่างสมบูรณ์ (Responsive ทั้งมือถือ, แท็บเล็ต และเดสก์ท็อป) พร้อมแถบเมนูล่างสำหรับมือถือ

### 2. 🛒 ตะกร้าสินค้าแบบสมบูรณ์ (Interactive Shopping Cart Drawer)
- ปุ่มเปิดตะกร้าพร้อมตัวเลขนับจำนวนสินค้าแบบเคลื่อนไหว (Bounce Animation)
- แถบแสดงยอดเงินสะสมเพื่อรับ **สิทธิ์ส่งฟรี (Free Shipping Progress Bar)** เมื่อช้อปครบ ฿1,500
- ปรับเพิ่ม/ลดจำนวนสินค้า หรือลบออกจากตะกร้าได้ทันที
- บันทึกข้อมูลลงใน `localStorage` ปิดหรือรีเฟรชหน้าเว็บ ข้อมูลสินค้าในตะกร้าไม่สูญหาย

### 3. 🎟️ ระบบโค้ดส่วนลด (Coupon Engine)
รองรับการกรอกโค้ดส่วนลดจริงพร้อมปุ่มคลิกใช้ด่วน:
- `SPORT20` : ลด 20% ทั้งตะกร้า
- `WELCOME10` : ลด 10% สำหรับลูกค้าใหม่
- `PULSE100` : ลด 100 บาท เมื่อช้อปครบ ฿800
- `FREESHIP` : ฟรีค่าจัดส่งทันที

### 4. 🔍 ตัวกรอง & ระบบค้นหาสินค้า (Filters & Live Search)
- **หมวดหมู่สินค้า:** รองเท้าวิ่งมาราธอน, รองเท้าบาสเก็ตบอล, รองเท้าสตั๊ดฟุตบอล, เสื้อผ้ากีฬาชาย, เสื้อผ้ากีฬาหญิง, อุปกรณ์และกระเป๋ายิม
- **ค้นหาแบบเรียลไทม์:** พิมพ์ชื่อรุ่น แบรนด์ สเปก หรือสี
- **ตัวกรองช่วงราคา (Price Range Slider):** เลื่อนปรับงบประมาณได้ตามต้องการ
- **จัดเรียงสินค้า (Sorting):** ยอดนิยม (ขายดีสุด), ราคา ต่ำ-สูง, ราคา สูง-ต่ำ, สินค้ามาใหม่, ส่วนลดสูงสุด, คะแนนรีวิว

### 5. 👁️ หน้ารายละเอียดสินค้าแบบ Quick View Modal
- คลังภาพสินค้า (Image Gallery) พร้อมรูปขนาดย่อให้คลิกเปลี่ยนมุมมอง
- ตัวเลือกสี (Color Swatches) ที่คลิกเปลี่ยนสีได้จริง
- ตัวเลือกไซส์ (Size Picker) ที่มีสถานะเลือกชัดเจน
- ปุ่มเปิดดู **ตารางเทียบไซส์มาตรฐาน (Size Guide)** ทั้งรองเท้า (EU/US/UK/CM) และเสื้อผ้า (รอบอก/รอบเอว)
- ข้อมูลจุดเด่นเทคโนโลยีและสเปกอย่างละเอียด
- ปุ่ม **"เพิ่มลงตะกร้า"** และปุ่ม **"สั่งซื้อทันที"**

### 6. ❤️ รายการโปรด (Wishlist System)
- กดไอคอนหัวใจเพื่อบันทึกสินค้าที่สนใจ
- หน้าต่างแสดงสินค้าที่ถูกใจ พร้อมปุ่มย้ายลงตะกร้าได้ทันที

### 7. 💳 ระบบจำลองการชำระเงิน (Checkout Flow)
- ฟอร์มกรอกชื่อ-เบอร์โทรศัพท์ และที่อยู่จัดส่งสินค้า
- ตัวเลือกการชำระเงิน 3 รูปแบบ:
  1. พร้อมเพย์ QR Code (PromptPay)
  2. บัตรเครดิต / เดบิต (Visa, Mastercard, JCB)
  3. เก็บเงินปลายทาง (Cash on Delivery - COD)
- หน้าสรุปคำสั่งซื้อเสร็จสมบูรณ์ พร้อมหมายเลข Order ID

## 🚀 วิธีเปิดใช้งานแอพพลิเคชัน (How to Run)

### วิธีที่ 1: ดับเบิ้ลคลิกเปิดผ่านบราวเซอร์ได้ทันที (ง่ายที่สุด)
- เพียงดับเบิ้ลคลิกไฟล์ `index.html` หรือคลิกขวาแล้วเลือกเปิดด้วย **Google Chrome**, **Microsoft Edge** หรือเว็บบราวเซอร์ใดก็ได้

### วิธีที่ 2: รันผ่าน Local Server (Node.js)
เปิดโปรแกรม Terminal หรือ Command Prompt ในโฟลเดอร์นี้ แล้วพิมพ์คำสั่ง:
```bash
node server.js
```
จากนั้นเปิดบราวเซอร์ไปที่:
👉 **http://localhost:3000**
